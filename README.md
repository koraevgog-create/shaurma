# SHAURMA LAB — центр управления запуском

Интерактивный бизнес-план и рабочая панель для запуска шаурмичной в Набережных Челнах.

## Возможности v1.0
- Обзор проекта и управленческие KPI
- Стратегия и конкуренты
- Сравнение трёх кандидатных помещений, добавление новых
- Концепция цветной шаурмы
- Редактор техкарт (ингредиенты, вес, закупочная цена, потери, упаковка, фудкост)
- Список оборудования и бюджетов
- Редактируемая инвестиционная смета
- Калькулятор выручки, расходов, маржи, безубыточности и простой окупаемости
- Калькулятор партнёрских долей и выплат
- Дорожная карта открытия
- Краткая презентация инвестору
- Локальное сохранение и экспорт/импорт JSON

## Как открыть сайт

Сайт статический, сборка и сервер не требуются.

В GitHub: **Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save**.

После публикации ориентировочный адрес: https://koraevgog-create.github.io/shaurma/

Если Pages ранее не был включён, следует дождаться первого опубликованного деплоя и проверить статус.

Для локального запуска нужен простой HTTP-сервер, например `python -m http.server 8000`; затем открыть `http://localhost:8000`. Двойной клик по index.html может не загрузить JS-модуль из-за политики CORS браузера.

## Хранение данных

**Важно:** данные сохраняются в localStorage **конкретного браузера** и не синхронизируются через GitHub. Рекомендуется регулярно нажимать «Экспортировать данные». Для переноса на другое устройство используется «Импортировать данные». Не храните в локальной версии персональные данные клиентов и конфиденциальную финансовую информацию.

## Статус данных

Все суммы, характеристики техники, ингредиенты и финмодель — **исходные гипотезы**, а не подтверждённые коммерческие предложения или утверждённые технологические карты. Комплектацию, обязательные требования и налоговую модель необходимо проверять перед запуском.
